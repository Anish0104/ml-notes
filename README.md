ML Notes
Personal learning notes for Machine Learning and Data Science fundamentals. This repository contains concise explanations, formulas, and examples built while practicing ML concepts and building projects.

Topics
Supervised Learning
Linear Regression: Predicts a continuous target variable by minimizing the Mean Squared Error (MSE) through techniques like Ordinary Least Squares (OLS) or Gradient Descent.

Logistic Regression: A classification algorithm that estimates the probability of a binary outcome using the Sigmoid function to map values between 0 and 1.

KNN (K-Nearest Neighbors): A non-parametric method that predicts a data point's label based on the 'K' closest examples in the feature space.

Decision Trees: Structures that make decisions based on feature values, utilizing metrics like Gini Impurity or Information Gain for splitting.

Unsupervised Learning
K-Means Clustering: An iterative process that partitions data into K non-overlapping clusters by minimizing the distance between points and their assigned centroids.

PCA (Principal Component Analysis): A dimensionality reduction technique that maximizes variance and minimizes information loss by projecting data onto lower-dimensional components.

Core Concepts
Train/Test Split: Dividing data into subsets to train the model on one portion and evaluate its performance on unseen data.

Bias vs Variance: The tradeoff between error from erroneous assumptions (underfitting) and error from sensitivity to training data noise (overfitting).

Feature Scaling: Techniques like Standardization and Normalization to ensure all features contribute equally to distance-based calculations.

Model Evaluation Metrics: Use of MAE/RMSE for regression and Precision, Recall, F1-Score, and Accuracy for classification tasks.

Tools
Python: Primary language for implementing machine learning workflows.

NumPy: Used for efficient numerical operations and handling multi-dimensional arrays.

Pandas: Used for data manipulation, cleaning, and feature engineering pipelines.

scikit-learn: Main library for implementing standardized machine learning algorithms and evaluation utilities.

Goal
Maintain structured notes while practicing ML concepts and building production-grade AI systems.
